Forecast how many GTA VI players earn each trophy in week one: an earners/players decomposition forecaster. Each trophy's rate is earners divided by players tracked, and the program models the two counts separately in log-time, so dilution falls out of the decomposition — when players join faster than earners accumulate, the rate falls; when the existing cohort progresses through the game, early trophies rise. The page Exophase prints is a snapshot from its last refresh, so the program also corrects for staleness using its own growth rates, and its spread grows honestly with the horizon (pinball loss punishes overconfidence).
